# anatomy 等轴测解剖图

这是一份可安装的技能正文。把它放到助手的 `workflows/anatomy/SKILL.md`。用户粘贴全文时，按下面的规则做可交互解剖，不要收成一段简介。

原设计仓库在 https://github.com/wheresryan22/anatomy 。本技能只负责原理解剖和动效拆解。

## 何时使用

- 原理拆解，需要把概念看成一台小机器。
- 落地页或文档里的精品技术插画，要带读数和缓动。
- 零件、表盘、导轨、弹簧这一类结构，数值要跟着模型变。

## 何时不用

- 45 种静态业务图解（架构、时序、流程、四象限、Sankey、甘特等）：交给 `diagram-design`。
- 社交或文章封面：交给 `cover_image_gen`。
- 改文案口吻：交给 `de-ai-writing`。

## 模型

零件和数字由同一模型驱动。先写一份数据：状态、范围、单位、当前值。SVG 上的表盘、刻度和读数都读这份数据，不在图形里另写一套对不上的数字。

交互至少包括一种状态变化（拖动、切换或播放）和与之对应的缓动。读数在状态变化时更新。

## 几何校验

需要 Node 20.10+ 和 Chrome 做几何校验时再开校验。环境不具备时，不要假装跑过校验；按设计规范出图，并在交付说明里写明「未跑几何校验」。

## 步骤

1. 用一句话写下这台小机器在演示什么原理。
2. 列出零件和它们共用的模型字段。
3. 画等轴测 SVG。表盘、导轨、弹簧只在它们确实解释这个原理时出现。
4. 接上同一种状态的缓动和读数。
5. 能跑校验就跑；不能跑就标明未校验。
6. 交付可打开的 SVG 或包含内联 SVG 的 HTML，以及模型字段说明。

## 输出

- 可交互的等轴测图。
- 模型字段和当前默认值。
- 不交付静态业务图解，不交付封面大图。
