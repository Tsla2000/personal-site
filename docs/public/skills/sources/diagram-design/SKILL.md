# diagram-design 图解设计

这是一份可安装的技能正文。把它放到助手的 `workflows/diagram-design/SKILL.md`。用户粘贴全文时，按下面的规则出图，不要收成一段简介。

静态图解的类型清单以已发布的用法为准：架构、时序、流程、飞轮、四象限、Sankey、甘特，以及用户点名的同类静态业务图。原设计仓库在 https://github.com/cathrynlavery/diagram-design 。本站使用的是按 promangofund.com 改过品牌色的版本，不另起一套配色。

## 何时使用

- 官网文章插图、方案汇报、技术说明里的静态结构图。
- 用户要一张能单独打开的图，而不是可交互的仪器。

## 何时不用

- 要「像小机器一样可交互拆解」的等轴测图：交给 `anatomy`。
- 文章封面、推文大图：交给 `cover_image_gen`。
- 改文案口吻：交给 `de-ai-writing`。

## 品牌

图内颜色只用这套 style-guide，不引入第二套品牌色：

- 纸：`#f8f8f5`
- 墨：`#26332d`
- 叶绿：`#355c4b`

纸做底，墨做文字和主线条，叶绿做强调和分组。需要更多层次时，只用这三色的透明度，不新增裸的装饰色。

## 输出

一份自包含 HTML：SVG 内联在文件里，不依赖外链样式、字体或图片。浏览器直接打开就能看到图。

图中文字用用户给出的原文，不擅自改成口号。中文标签要能读完，不缩成看不清的字。

## 步骤

1. 确认图的类型。用户没指定时，在架构、时序、流程、飞轮、四象限、Sankey、甘特里选最贴近的一种，并先说选择。
2. 列出节点、方向和必须出现的标签。缺数据就问，不编数量级。
3. 按品牌色画静态 SVG，放进自包含 HTML。
4. 检查：没有外链、没有脚本依赖、文字没有溢出、颜色只来自纸 / 墨 / 叶绿。
5. 把 HTML 交给用户。不把同一张图再做成等轴测解剖。

## 分工

静态图解用本技能。交互解剖和动效用 `anatomy`。封面用 `cover_image_gen`。
