# UI 设计参考清单

适用：个人站、作品集、品牌站、SaaS 落地页的视觉与组件选型。完整表见 `references/ui-catalog.md`。

条目整理自公开分享（《从0搭建个人网站：8大类60+UI设计必备清单》，PamelaAI·H @pamelaaaaa1218），改写为 Agent 选型清单，不替代各站官方文档。

## 工作流

1. 读调用方气质、技术栈、商用需求。
2. 打开 `references/ui-catalog.md`：每个品类最多挑 **1–3** 个链接。
3. 对每个候选：打开页面 → 记下可复用点（布局/组件/动效/配色）→ 检查授权与栈兼容。
4. 把「选中的链接 + 要抄的点 + 不要抄的品牌资产」写进实现简报，再写代码。
5. 若只需内容与发布流程，改用技能「个人网站搭建」；若要反 AI 默认审美，启用「frontend-design」。

## 品类速查

| 品类 | 何时打开 |
|---|---|
| 组件 | 需要按钮、表单、导航、卡片、营销区块 |
| 动效与 3D | 需要滚动、光效、Lottie、WebGL、Spline/Rive |
| 整站灵感 | 定首页气质与信息架构 |
| 产品界面与流程 | 做真实产品流程（登录、订阅、设置） |
| 局部灵感与微交互 | 只要一个小交互或构图参考 |
| 配色图标素材 | 定色板、图标集、插画/摄影 |
| AI 建站 | 快速出方案/原型，再手工收 |
| 设计 Skill | 给编程助手装设计规则或提示词 |

## 硬规则

- 不要一次引用超过 3 个重动效库。
- 不要把参考站的 Logo、插画版权素材、品牌色原样搬进客户站。
- Tailwind Plus 等付费库：未购买只作视觉参考。
- Shadertoy 等社区素材：落地前查授权。
- 旧入口以 catalog 备注为准（如 Galileo→Stitch，screenlane→Page Flows）。

## 与商店其他技能

- `个人网站搭建`：飞书底稿 + 发布检查。
- `frontend-design`（Anthropic）：反模板审美的前端实现。
- `AI界面设计规范`：聊天/Agent 产品前端细节。
- Impeccable：本清单只给安装入口；完整能力见 https://impeccable.style/
