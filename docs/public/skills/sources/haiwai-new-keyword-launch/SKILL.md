# 出海新词上站

适用：副业出海、新词/梗站、SEO+GEO 抢红利期。目标是「当天可点开的站 + 长尾承接」，不是一次做完产品再上线。

本流程提炼自 @JiangK82705（蒋云何）公开复盘《副业出海小白 首日破百刀，5天破千刀的新词经验分享》，改写成 Agent 可执行步骤；工具与 URL 见 `references/tools.md`。不捏造原文未写数据；作者自有 `.app` 域名勿臆造。

变现、定价、埋点、留存见技能「出海变现转化」。

## 0. 开工前确认

向调用方确认并写进简报：

1. **词根候选**：已有词根列表，还是从零建？
2. **上站栈**：未指定时默认 ShipAny 模板 + Cloudflare 全家桶（库/存储/托管，无需自购服务器）。
3. **域名偏好**：优先 `.com`；没有则 `.app` 等贴词后缀（Spaceship 购买）。
4. **时间窗口**：新词红利期短（原文案例约一周量级），以「当天上首页」为硬约束。

## 1. 需求入口：SEO + GEO

全球用户找工具的入口主要是：

| 入口 | 能做什么 |
|---|---|
| Google 搜索（SEO） | 看搜什么、SERP 谁占坑、长尾词 |
| ChatGPT 等 AI（GEO） | 难直接看到问句，但可靠「早上线 + 答用户问题的文案/FAQ/长尾页」被引用 |

优先能观测的一侧：用 **Google Trends**（https://trends.google.com/trends/explore）找上升查询；GEO 靠内容与上线速度补。

## 2. Google Trends 词根法

1. 选一个**简单高频词根**（代表一类需求，如 `AI`），在 Trends 里搜索。
2. 打开「相关查询」，切到「**搜索量上升**」。
3. 记下飙升组合词（例：原文看到 `hotel lobby ai video`）。
4. 用 **TrendsBar** 插件看该词热度，并扫相关域名是否已被注册。
5. 不懂词义时，先让 AI 解释需求再决定是否做；不要因不懂英文词就跳过。

原则：新手优先新词（短期正反馈更容易）；老词竞争大，需持续投入才有稳定收入——本技能默认走新词路径。

## 3. 四点判断：值不值得马上做

四条都偏「是」再开干；任一明显否，换下一个词。

1. **在飙升**：出现在 Trends「搜索量上升」里。
2. **对比 GPTs**：用 TrendsBar 把新词和 `GPTs` 对比；热度抬头并追平/接近时，适合立刻做。
3. **SERP 未被专门站占住**：谷歌前排若是 YouTube 教程、资讯、Reddit，再才是大站内页 → 机会大；若已有垂直专门站霸占前排 → 慎做。
4. **域名可买**：`.com` 没了就立刻买 `.app` 等；买域名用 **Spaceship**（https://www.spaceship.com/）。

## 4. 词根沉淀

1. 维护一份**自有词根列表**（表格或笔记即可）：词根、代表需求、上次扫描日期、备注。
2. 可在 TrendsBar 里加入自己关注的词根（不只依赖别人公开的几十个）。
3. 每个词根定期扫「相关查询 → 搜索量上升」，命中后走第 3 节四点判断。

## 5. D0–D5 上站 SOP

用现成 AI 模板加速；原文用 **ShipAny**。托管与后端能力优先 **Cloudflare**（https://www.cloudflare.com/）。速度优先：第一版可以是静态 HTML 页。

| 日 | 动作 | 不做 |
|---|---|---|
| **D0** | 找到词**当天**上首页：复刻竞品大站相关内页结构；可加「假生成」提升停留（见变现技能）。登录/支付可后置。 | 追求完美功能 |
| **D1–D2** | **不做功能**；用长尾词批量铺内页（见第 6 节）。可辅助外链（如 Auto Register Filler、付费导航），主流量仍靠文案与内容。 | 先堆功能再铺词 |
| **D3** | 见流量（尤其 chatgpt.com / 自然搜索）→ **先上登录**看用户从哪来；再晚上冲功能与支付。 | 无流量也先做重功能 |
| **D4** | 上支付与真实生成；套餐可先照抄竞品再改。有订单没付款 → 改套餐文案价值主张。 | 文案不动只怪支付 |
| **D5 往后** | 数据驱动：流量下滑、用户偏「只玩一次」→ 补低价积分包等（细节见变现技能）。 | 热度退潮还只怪 SEO |

## 6. 长尾四来源

把词交给 AI **批量生成内页**，覆盖用户可能的问法：

1. **谷歌下拉框**建议词  
2. **GSC**（Google Search Console）热门查询  
3. **SimilarWeb** 关键词生成器：以主词为种子拉相关词  
4. **竞品自然流量关键词**（SimilarWeb 等看竞品大站吃哪些词）

上线后盯 GSC：点击、展示、平均排名；注意高点击词可能不是主词（可能贴合你被迫选的域名后缀）。

## 7. GEO 三件事（先内容，后功能）

让 AI 推荐站点时，按这三件事执行：

1. **FAQ / 文案按用户会问的问题写**（写法可先模仿竞品），先内容后功能。  
2. **长尾内页**覆盖各种关键词，用户问什么都有页能答。  
3. **上线早**：登录与支付可后置；无登录阶段也要有可索引、可被引用的页面。

注意：GEO 红利在竞争少的前几天最明显；梗热度退潮时 chatgpt.com 流量往往掉得最狠——提前按变现技能做留存与分享，不要「生成完就结束」。

## 8. 工具用途速查

完整 URL 见 `references/tools.md`。

| 工具 | 用途 |
|---|---|
| Google Trends | 词根 → 相关查询 → 搜索量上升 |
| TrendsBar | 热度对比（如 vs GPTs）、域名是否已注册 |
| Spaceship | 买域名（.com / .app） |
| ShipAny | AI 建站模板，加快上站 |
| Cloudflare | 托管、数据库、存储等全家桶 |
| GSC | 收录后看查询、点击、排名 |
| SimilarWeb | 关键词生成器 + 竞品自然词 |
| Auto Register Filler | 外链注册辅助（Chrome） |
| GA4 | 日活、来源（含 chatgpt.com） |
| Artificial Analysis | 按成本与分数选模型（功能期） |

## 9. 不要做什么

- 不要等功能完美再上站；新词窗口按天计。  
- 不要跳过四点判断直接买域、上站。  
- 不要只发导航站外链当主策略；导航站注册转化常偏低。  
- 不要编造作者未公开的完整产品域名。  
- 不要把本技能里的案例数字当成你站的承诺指标。

写在最后：选词 → 当天首页 → 长尾 → 见量再登录支付。速度与内容质量同时抓。
