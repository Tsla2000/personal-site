# 去AI味写作（de-ai-writing）

## 总规则（每次触发都适用）
1. **永远读最新版**：每次触发都重新读本文件"用户原提示词"一节和对应风格档案的当前内容，不凭记忆沿用旧版。
2. **优先级**：风格档案 > 第三方规则集（lieflat-less-ai-tone）。档案记录的写法即使疑似命中清理规则也不改。
3. **最小改动 + 信息守恒**：不新增姓名、数字、日期、引语、来源、因果、细节；不删观点、结论、限定词（可能/通常/据说）；不碰结构。
4. 风格档案位置：`/cursor/stores/store-2a9112d2-b476-44e2-84a0-3a7cdb71ac80/writing-style/<作者代号>.md`。找不到时：请用户提供档案文件，或提供 2 篇以上本人文章作语料，先跑场景一。不要无档案凭感觉"去AI味"。
5. 用户更新提示词时，只替换"用户原提示词"一节（保持逐字），并在档案目录的 `CHANGELOG.md` 记日期。

# 分析方法（分三遍，每遍任务不同，不许合并）

**第一遍：通读**
所有文章从头到尾读一遍，不做笔记。目的是建立整体印象，感受作者的说话姿态。

**第二遍：抽样统计**
从每篇里各抽 3-5 段，做下面几项统计，数据留在档案里作为规则的支撑证据：
- 平均句长（按逗号切成的短单位算，单位：字）
- 段落长度分布：单句成段占比 / 1-3 句段占比 / 4 句以上段占比
- 每千字高频助词出现次数（呢 / 吧 / 哈 / 嘛 / 啊 / 啦 / 哦 / 嘿嘿……逐个统计）
- 每千字第一人称「我」和第二人称「你 / 你们 / 朋友们」的出现比例

**第三遍：规律提炼**
按下面四个维度提炼规律，每一条规律都必须同时具备：
①至少 2 条语料证据　②作用说明　③使用边界。缺一不写。

## 维度一 · 句子

- 长句怎么切？逗号在什么位置？断句点选择的规律？
- 段落怎么组织？信息高密度处段落更短还是更长？
- 有没有固定的推进句式（比方说先承认再修正、把复杂事一句话降维、
  主动划出「不适合谁」等等）？分别用在什么位置？

## 维度二 · 用词

- 高频助词的分布和各自的作用（每种助词单独看）
- 固定用词清单：称呼读者用什么、举例用什么、换气开新段用什么、
  动手动词用什么、判断类形容词用什么、模糊量化词用什么 —— 每一类给出实际用词
- 明显缺席的词（对照同类型写作者的常见用词，标出这个作者明显不用的）

## 维度三 · 过渡

- 章节之间的过渡方式（是不是有「把上一节做完的事复述半句 + 引出下一节」这类模板？）
- 段落之间的过渡方式
- 长文里有没有回旋引用（反复回到同一个真实案例）？

## 维度四 · 姿态

- 「我」和「你」怎么切换：什么内容归「我」、什么内容归「你」
- 建立信任的动作：暴露失败 / 标注边界 / 让功给别人 / 主动标广告 —— 分别在哪些位置出现
- 冗余度：作者允许自己冗余、拖沓到什么程度？靠什么语料证据判断？

# 铁律

## 场景一：提炼风格档案
1. 严格按上方"用户原提示词"执行三遍分析，三遍不合并。
2. 第二遍统计**必须**用脚本真实计算：对每篇抽样段落存成文件后运行 `python3 /home/box/agent-data/workflows/de-ai-writing/scripts/style_stats.py <文件...>`，把数字原样写进档案"统计概览"（提示词要求的"按逗号切成的短单位"对应脚本的"短单位长"）。

4. 存档到 `/cursor/stores/store-2a9112d2-b476-44e2-84a0-3a7cdb71ac80/writing-style/<作者代号>.md`（例：`某作者.md`），告诉用户路径。

## 场景二：按档案写作
1. 先读完整份档案；按句子/用词/过渡/姿态四层规律写；写完用档案"总闸"判据自检，可用脚本对比成稿与档案统计是否接近。
2. 子模板：
   - **公众号文章**：标题与结构由用户/选题决定（档案不管结构）；正文表达层严格按档案；如作者有"主动标广告/标注边界/不适合谁"等姿态，按档案位置使用。
   - **投资简报**：①先列出所有数据点（价格、涨跌幅、财报数字、日期）及来源，逐条联网核对口径与时点，核对不了的标"待核实"不写死；②正文按档案表达层写，数据保持原值不做概括；③结尾留免责声明位：`【免责声明：___（由用户提供或确认措辞）】`，默认"本文仅为个人观点记录，不构成投资建议"需用户确认。
3. 初稿完成后进入场景三清理。
