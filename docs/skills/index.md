# 技能商店

不是一堆泛用提示词，而是能直接交给 Agent 执行的工作流程。优先整理了 8 个结果导向的方向：从 AI 项目交付、网站发布，到增长、内容、自动化与数据分析。

**怎么用：** 按场景筛选技能 → 复制 SKILL.md 或下载 ZIP → 放进支持 Skills 的 Agent → 用自己的项目和目标启动。技能会提供流程、检查点与验收标准；具体执行结果仍需在你的环境中验证。

- [AI Coding 项目交付流程：从需求到可验收成果](../ai/workflows/ai-project-delivery-workflow)：需求澄清、分步实现、测试和交接。
- [网站上线检查清单：部署前验证功能、SEO、移动端与回滚](../ai/workflows/website-launch-checklist)：发布前的功能、搜索、移动端与回滚检查。

这些指南提供可复用的流程和检查点；具体项目仍应根据实际环境验证。
