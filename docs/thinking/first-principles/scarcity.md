# 当智能可以无限复制，什么才是真正稀缺？

<div class="meta-line">2026.10.05 · 思考 · 阅读约 4 分钟</div>

人类社会长期把智力当作一种稀缺资源。优秀的研究者、工程师、管理者和创作者需要经过多年训练，他们的时间有限，因此他们的判断很昂贵。

如果智能可以被复制，情况会发生变化。一个好的方法可以被同时部署到无数个任务中，分析、写作、编程和研究的边际成本都会下降。过去由“谁更聪明”决定的差距，可能转移到别的地方。

我认为至少有四种稀缺性会变得更重要：

- **注意力**：人仍然只能关注有限的事情。
- **信任**：在信息泛滥时，谁值得相信会更难判断。
- **真实经验**：模型可以组合已有知识，但生活、关系和承担后果仍然属于具体的人。
- **方向感**：当实现方案变得便宜，选择什么目标反而更重要。

技术不会消灭稀缺性，只会重新安排稀缺性。真正的问题不是“AI 会不会让一切都变得容易”，而是当容易完成的事情越来越多，我们愿意把有限生命用于什么。
