# 财富的第一性原理是什么？

<div class="meta-line">2026.09.10 · 思考 · 阅读约 3 分钟</div>

账户上的数字只是记录。

更底层的财富，是一个人或一个组织在未来调度资源的能力。

![财富：未来选择权的储存](/images/wealth-option.webp)

## 财富和账户上的数字，是一回事吗？

这种能力来自几个部分。

可持续的生产能力、可信任的关系和对风险的承受能力，再加上在变化发生时重新配置资源的自由。

## 收入和财富，到底哪里不一样？

收入和财富不是同一个概念。

收入是某一段时间内创造价值的流量，财富则是把未来的选择权保存下来。

一个人赚很多钱，却被高固定成本和单一技能锁住，未必拥有真正的自由。

## 所以，投资到底在投什么？

从这个角度看，投资是在构建选择权，寻找更高回报只是其中一部分。

现金、健康、技能是财富，关系和信誉也是。
