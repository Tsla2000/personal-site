# 财富的第一性原理是什么？

<div class="meta-line">2026.09.10 · 思考 · 阅读约 3 分钟</div>

财富常常被等同于账户上的数字，但数字只是记录。更底层的财富，是一个人或一个组织在未来调度资源的能力。

这种能力来自几个部分：可持续的生产能力、可信任的关系、对风险的承受能力，以及在变化发生时重新配置资源的自由。

因此，收入和财富不是同一个概念。收入是某一段时间内创造价值的流量，财富则是把未来的选择权保存下来。一个人赚很多钱，却被高固定成本和单一技能锁住，未必拥有真正的自由。

从这个角度看，投资不只是寻找更高回报，也是构建选择权。现金、健康、技能、关系和信誉，都可能是财富的一部分。
